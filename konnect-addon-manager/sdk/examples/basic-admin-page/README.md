# Basic admin page

`konnect.demo` v1.0.0 copies one Blade view and registers an admin page and menu.
The enabled route is `/admin/konnect-addons/extensions/konnect.demo/status`.
No Panel frontend build or database migration is required.

This is a development example for the declared Panel version, not a production
compatibility certification. Initial installation still requires a matching
source adapter and a supported isolated validation runner. See the manager's
administrator and developer guides before using an executable addon.
